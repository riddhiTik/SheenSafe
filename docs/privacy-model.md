# Privacy model

## Default posture

Local-first, minimal-data, refugee-safety-aware.

## Do not collect by default

- Continuous GPS trail.
- Full raw health history on volunteer dashboards.
- Biometric identity data.
- Data for advertising or monetization.
- Data sharing with authorities.

## Collect only when needed

- Approximate camp zone for heat/weather risk.
- Ring health signals needed for alerting.
- Emergency contact.
- Alert event history.
- Volunteer acknowledgement history.

## Access control

Volunteer users should see:

- Assigned user alias.
- Current risk level.
- Last ring signal time.
- Ring battery issue.
- Contact action.
- Short structured notes.

Volunteer users should not see full raw vitals unless explicitly authorized for a medical workflow.

## Retention

Suggested MVP retention:

- Raw ring samples: 7 to 30 days.
- Risk decisions: 30 to 90 days.
- Emergency alert audit: longer only if required by program governance.
- User deletion: available from admin workflow.
