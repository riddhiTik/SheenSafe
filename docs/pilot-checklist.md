# Pilot checklist

## Hardware

- 20+ rings tested.
- Each ring labeled.
- Charger inventory recorded.
- Battery reporting validated.
- Pairing instructions written.
- Replacement process prepared.

## App

- Local language strings reviewed.
- Emergency contact set for every user.
- Manual weather/camp-zone workflow tested.
- Foreground notification visible.
- Alert notification audible and visible.
- Share/call intents tested on target phones.

## Operations

- Volunteer roster assigned.
- Escalation protocol written.
- Emergency numbers verified.
- Privacy consent process rehearsed.
- Data deletion process available.
- Incident review process scheduled.

## Safety metrics

- Pairing success rate.
- Daily data coverage.
- Alert acknowledgement rate.
- Volunteer response time.
- False emergency alerts.
- Missed high-risk symptom reports.
- User comprehension of each risk state.
